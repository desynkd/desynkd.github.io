Headings and lists

Use <h2> for sections and <h3> below them. The post title is the page's <h1>, so never add another.

Figures

A default <figure> sits in the right-hand rail on wide screens, so the text keeps flowing beside it. That suits screenshots and supporting images that you can glance at without losing your place. Consecutive figures stack in the rail rather than overlapping.

When an image is the point, add class="wide". A wide figure spans the full article width, starts below any floated figure, and stays exactly where it is in the text on mobile.

Callouts

Note. A callout sets an aside apart from the prose — a caveat, a tip, a tangent. It can hold several paragraphs and inline code.

Code

Write a code block as <pre><code class="language-…">. The build highlights it with the site's monochrome theme and strips the indentation it inherits from the surrounding HTML. Escape < and & inside it.


  export function readingTime(words: number): number {
    // 200 words a minute, never less than one.
    return Math.max(1, Math.round(words / 200));
  }

Stages

A .stage is a full-width frame for anything interactive — a canvas, a demo, a diagram. The frame comes from the shared styles; everything inside it is the post's own. The one below is an ordered dither, coloured from the site's tokens. Move the pointer across it.

Need a library? Import it from a CDN at an exact version, the way an artifact would — for example import * as THREE from "https://cdn.jsdelivr.net/npm/three@0.183.2/+esm".
